# AI IT Helpdesk

An AI-powered IT Helpdesk and Intelligent Incident Management System.

## Overview

This project provides a centralized platform for managing IT support
incidents while using AI to assist with incident classification,
priority determination, and resolution recommendations.

## Planned Features

- User authentication
- Employee ticket creation
- IT support ticket management
- AI-based ticket classification
- AI-generated resolution recommendations
- Priority management
- Ticket assignment
- Incident status tracking
- Admin dashboard
- Analytics

## Technology Stack

- React
- Node.js
- Express.js
- MongoDB
- Gemini API
